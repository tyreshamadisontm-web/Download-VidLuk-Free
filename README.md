# AI Clipping Tool — Personal Use

Simple workflow:

1. Upload a video.
2. Detect potential clips.
3. Generate the selected clips.
4. Download the finished clips.

The project is organized with `public/` and `server/` at the repository root so Render can resolve paths correctly.

This project is intended for personal use. AI/cloud services may have their own free-tier limits or require accounts; the app itself does not guarantee unlimited free third-party AI processing.
